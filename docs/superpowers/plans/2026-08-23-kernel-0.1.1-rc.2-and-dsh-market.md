# 内核升级 0.1.0-rc.7 → 0.1.1-rc.2 + 内置 dsh-market 插件市场 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 v4Lite 桌面端内核从 `@deepseek-ai/dsh` 0.1.0-rc.7 升级到上游最新 0.1.1-rc.2（npm 已全量发布），内置社区插件市场 dsh-market，保证既有功能零回归、打包可安装、v4.4.1 用户可原地升级。

**Architecture:** 桌面壳（Electron main.js / Tauri sidecar）把内核 CLI 作为 npm 依赖打包并以内置 node.exe 启动 `dsh web`。升级 = 依赖版本整体提升 + 三处集成面适配（`--no-open`、pnpm 补丁目标、清单测试）。dsh-market 以配套插件形式进 `assets/plugins/`，复用现有 companion 同步机制。所有构建缓存重定向 D 盘（C 盘仅剩 ~2GB）。

**Tech Stack:** Electron 43 + electron-builder(NSIS)、Node 24（vendored）、node:test、Tauri sidecar(Rust，源码同 parity 改动)、npm registry。

**约束：**
- 遵守 TDD（test-driven-development 技能）：行为改动先写失败测试。
- 不做 git commit（除非用户明确要求）；每步以测试/命令输出为验收。
- 内核源码参考副本在 `D:\dsh-kernel-src-tmp\deepseek-harness-master`（已解压，只读参考；结束时可删）。

- [ ] **Step 1: 写冒烟脚本** —— 复刻 main.js 的拉起方式：

```js
'use strict';
const { spawn } = require('node:child_process');
const path = require('node:path');
const fs = require('node:fs');

const ROOT = __dirname, '..';
const home = 'D:\\dsh-smoke-home';
fs.rmSync(home, { recursive: true, force: true });
fs.mkdirSync(home, { recursive: true });
const bin = require.resolve('@deepseek-ai/dsh/lib/bin.js', { paths: [path.join(ROOT, '..')] });
const nodeExe = path.join(ROOT, '..', 'vendor', 'node', 'node.exe');
const child = spawn(nodeExe, ['--use-system-ca', bin, '--profile', 'web-desktop',
  '--host', '127.0.0.1', '--port', '3999', '--no-open'], {
  env: { ...process.env, DSH_HOME: home, DSH_DESKTOP_PROFILE: 'web-desktop', npm_config_store_dir: 'D:\\dsh-build-cache\\pnpm-store' },
  cwd: home,
});
let buf = '';
const timer = setTimeout(() => { console.error('SMOKE TIMEOUT'); child.kill('SIGKILL'); process.exit(2); }, 180000);
child.stdout.on('data', (d) => {
  buf += d; process.stdout.write(d);
  const m = buf.match(/dsh web:\s+(https?:\/\/\S+)/);
  if (m) {
    fetch(m[1]).then((r) => {
      console.log('\nSMOKE OK http', r.status);
      clearTimeout(timer); child.kill('SIGKILL'); process.exit(0);
    }).catch((e) => { console.error('SMOKE HTTP FAIL', e); child.kill('SIGKILL'); process.exit(3); });
  }
});
child.stderr.on('data', (d) => process.stderr.write(d));
child.on('exit', (c) => { clearTimeout(timer); console.error('SMOKE EXIT', c); process.exit(c || 4); });
```
